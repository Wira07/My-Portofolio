## Konteks

Calon klien B2B maupun UMKM sering ragu menghubungi software house ketika situs webnya tidak menjelaskan secara konkret siapa tim di baliknya, bagaimana alur garansi pasca-rilis, dan layanan teknis apa saja yang ditangani secara in-house.

## Masalah

1. **Keseragaman visual dan kecepatan muat**: Website agensi wajib terasa modern sekaligus tetap ringan di jaringan seluler Indonesia.
2. **Edukasi awal calon klien**: Pertanyaan berulang mengenai kepemilikan source code, MoU, dan skema garansi perlu terjawab sebelum sesi konsultasi dimulai.
3. **Pemeliharaan konten layanan**: Tim internal perlu kemudahan memperbarui daftar layanan dan portofolio melalui struktur Blade yang rapi.

## Pendekatan & Keputusan Teknis (Trade-Off)

- **Laravel Blade + Tailwind CSS dibanding SPA Full Client-Side**: Karena sebagian besar halaman berupa profil layanan, studi kasus, dan profil tim yang menuntut pengindeksan SEO kuat, rendering di server dengan Blade memberikan Time-to-First-Byte yang stabil tanpa kompleksitas state SPA. *Trade-off*: transisi antar-halaman memakai navigasi multipage standar dengan peningkatan progresif di sisi klien.
- **Simulasi Konsultasi Terpandu**: Menyematkan komponen dialog interaktif di halaman layanan untuk memandu calon klien menanyakan garansi, kepemilikan kode, dan estimasi waktu sebelum diteruskan ke WhatsApp.

## Arsitektur

Laravel melayani rute publik dengan komponen Blade modular, memisahkan konfigurasi layanan dan anggota tim, serta menyematkan modul JavaScript ringan untuk simulasi tanya jawab proyek.

## Hasil

- Situs resmi **techop.id** terstruktur dalam empat jalur layanan inti (Web, UI/UX, Mobile App, Game Dev), halaman tim transparan, dan alur simulasi konsultasi langsung.
- Data konversi jangka panjang ditandai untuk evaluasi analytics berkelanjutan.

## Pelajaran

Menampilkan kejelasan kontrak kerja (hak milik kode, garansi pemeliharaan, dan transparansi tim) pada lapisan informasi utama meningkatkan kualitas pertanyaan masuk dari calon klien.
