## Konteks

Aplikasi pembelajaran ibadah membutuhkan umpan balik langsung bagi pengguna ketika berlatih urutan gerakan salat tanpa harus selalu terhubung ke koneksi internet berkecepatan tinggi maupun mengirimkan video pribadi ke server cloud.

## Masalah

1. **Keterbatasan privasi & jaringan**: Mengirim frame kamera terus-menerus ke server menimbulkan latensi tinggi sekaligus isu privasi pengguna.
2. **Perbedaan format tensor antara Python dan Android**: Output tensor YOLO harus dipetakan ulang dengan benar pada sisi Kotlin (skala koordinat, orientasi rotasi kamera, dan Non-Maximum Suppression).
3. **Keseimbangan akurasi vs ukuran APK**: Model deteksi penuh terlalu berat untuk dijalankan langsung di ponsel Android tanpa konversi dan kuantisasi.

## Pendekatan & Keputusan Teknis (Trade-Off)

- **On-Device Inference dengan TensorFlow Lite dibanding Cloud API**: Memilih menjalankan model 7 kelas secara penuh di perangkat menjamin latensi rendah, nol biaya server GPU per pengguna, dan privasi video terjaga 100%. *Trade-off*: membutuhkan penyesuaian ketat pada ukuran input tensor dan *Non-Maximum Suppression* manual di Kotlin.
- **Konversi Bertahap YOLO11 → TFLite Terkuantisasi**: Memangkas ukuran bobot dan memanfaatkan akselerator Android (NNAPI / GPU delegate dengan fallback CPU) agar tetap stabil pada perangkat target.

## Arsitektur

Model 7 kelas dilatih menggunakan Python YOLO11, diekspor ke berkas `.tflite`, dibundel sebagai aset di aplikasi Android, dan dijalankan oleh `CameraX ImageAnalysis` yang memperbarui overlay antarmuka secara real-time.

## Hasil

- Aplikasi Android mampu memuat dan menjalankan deteksi 7 kelas gerakan langsung dari kamera secara offline.
- Benchmark latensi milidetik dan ukuran berkas kuantisasi final masih tercatat sebagai draft terverifikasi sampai pengujian lintas perangkat selesai.

## Pelajaran

Keberhasilan AI di Android ditentukan di titik perbatasan antara Python dan Kotlin: memverifikasi dimensi tensor, normalisasi warna (RGB vs BGR), dan rotasi sensor kamera sejak hari pertama menghemat puluhan jam debugging.
