## Context

Static selfie or PIN-based check-ins are trivially bypassed with printed photos or second phone screens. **Smart Attendance AI** combines native Android camera capture with layered computer vision verification.

## Problem

1. **Inconsistent doorway lighting** degrades naive facial embedding accuracy.
2. **Presentation attacks (spoofing)** must be rejected prior to recording any attendance log.
3. **Mid-range Android memory limits** require bounding frame size and processing cost so the preview stays responsive.

## Approach & Technical Trade-Offs

- **YOLO11 ROI Extraction Before Recognition**: Cropping clean face regions via YOLO11 cuts background noise before liveness and recognition run. *Trade-off*: adds an explicit detection pass while lowering false matches in crowded entrances.
- **Prompted Motion Liveness**: Avoids relying on hardware depth sensors absent across most budget Android handsets.

## Architecture

Kotlin CameraX supplies preview buffers to the YOLO11 face detector, validates genuine human motion, and compares identity vectors against registered profiles before writing to the attendance API.

## Outcomes

- Unified multi-stage detection, anti-spoofing, and attendance submission flow built end-to-end.
- Formal device benchmarks remain withheld for verification pending mid-tier handset test sweeps.

## Lessons Learned

Biometric reliability in production depends heavily on camera UX guidance — lighting cues, distance framing, and clear retry prompts — alongside model precision.
